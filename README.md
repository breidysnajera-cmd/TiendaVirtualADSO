# TiendaVirtualADSO

# Mi tienda virtual

## Objetivo
Desarrollar una tienda virtual que permita a los usuarios conocer los productos disponibles y facilitar el proceso de compra por internet.

## Funciones principales
1. **Catálogo de productos:** mostrar los productos con sus nombres, imágenes, precios y descripciones.
2. **Gestión de compras:** permitir a los usuarios seleccionar productos y realizar pedidos.
